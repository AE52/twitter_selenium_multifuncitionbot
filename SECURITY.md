# Security policy

## Supported versions

This project is currently pre-1.0. Security fixes are applied to the default branch.

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities involving credential handling or account takeover risk. Instead, contact the maintainers privately through the repository owner's preferred security contact.

## Secrets

Never commit `.env` files, passwords, cookies, browser profiles, or exported session storage. Rotate credentials immediately if they were committed accidentally.
